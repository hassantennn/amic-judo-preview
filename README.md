# AMIC Judo client design preview

Website: https://hassantennn.github.io/amic-judo-preview/

Static design preview for AMIC Judo in Aberdeen. Includes the supplied club branding, introduction, venue, phone number and class timetable.

Membership types, prices, terms, coach information and the public email address are still being finalised. Signup, payments and contact-form submission are not enabled.

Only public pages and assets are included. No database, API, private member pages or email outbox is published.
